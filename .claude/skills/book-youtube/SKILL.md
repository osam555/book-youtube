# book-youtube — 책 홍보 시네마틱 3부작 쇼츠 (book-youtube-kit 설치본)

키트 위치: `{{KIT_DIR}}` (이 폴더 안에서 claude 를 열었다면 현재 폴더). 모든 명령은 **키트 폴더에서** 실행한다.

**파이썬은 가상환경 것을 쓴다:**
- Windows: `.venv\Scripts\python.exe`
- macOS: `.venv/bin/python`
아래에서 `PY` 는 이것을 뜻한다. `.venv` 가 없으면 설치가 안 된 것 → README 의 설치(`setup.ps1` / `setup.sh`)부터.

## 0. 시작 전 확인
- `.env` 에 `GEMINI_API_KEY`·`TYPECAST_API_KEY` 가 있어야 한다. **키 값을 화면에 출력하거나 파일에 옮겨 적지 않는다.** 없으면 사용자에게 `.env` 를 열어 넣으라고 안내.
- `ffmpeg`, `npx` 가 PATH 에 있어야 한다(설치 직후엔 새 터미널).

## 1. 책 찾기 → 근거 모으기
```
PY tools/book_research.py "책 이름" [--author 저자] [--yes24 상품번호]
```
→ `books/<책이름>/book.json`(제목·저자·출판사·표지·예스24/교보 링크), `sources.md`(책소개·목차·책 속으로·출판사 리뷰·저자 소개 원문), `cover.jpg`.
- 결과의 제목·저자가 사용자가 말한 책과 같은지 **반드시 확인**하고 사용자에게 한 줄로 보고. 다르면 `--author`·`--yes24` 로 다시.
- 교보 링크(`kyobo_url`)가 비었으면 웹 검색으로 찾고, 못 찾으면 예스24 링크를 쓴다.
- 사용자가 책 PDF 를 갖고 있으면 `books/<책>/book.pdf` 에 두고 `PY tools/pdf_text.py books/<책>/book.pdf` → `book.txt` 도 근거로 쓴다(근거가 훨씬 많아진다). PDF 는 권리자에게 받은 것만.
- 웹 검색(WebSearch)으로 저자 인터뷰·출판사 소개를 더 볼 수는 있지만, **원고의 근거는 sources.md·book.txt 에 있는 문장만** 쓴다(다른 자료에서 쓰고 싶으면 그 원문을 sources.md 끝에 「## 추가 자료 (URL)」로 붙인 뒤).

## 2. 3부작 기획
`sources.md` 를 다 읽고 1·2·3부를 제안해 사용자 확인을 받는다.

| 편 | 역할 | 예 (대충영어) |
|---|---|---|
| 1부 | 문제 제기 + 저자 권위 | 「영어 10년 했는데 왜 아직도 안 될까?」 → 영어가 무기였던 외교관도 못 알아들었다 |
| 2부 | 감정 서사(독자가 겪는 장면) | 완벽하려다 말 한마디 못 한 사람 |
| 3부 | 우화·반전·원칙 | 「대충 하라, 외우지 마라, 짧게 하라」 |

**첫 줄 = 훅**: 질문 + 구체적 숫자/인물. 추상적인 훅(「돈보다 먼저 물려줘야 할 것」)보다 숫자·인물 훅이 잘 된다.

## 3. 원고 쓰기 — `books/<책>/partN.json`
견본: `books/대충영어/part1.json`. 형식:
```json
{"id":"part1", "title_top":["윗줄","아랫줄"], "title_sub":"작은 부제", "voice":"Jiseon",
 "lines":[{"cap":"자막 앞조각|뒷조각", "say":"소리 글", "evidence":"출처 「책 원문 그대로」", "img":"영어 장면 묘사"}, …,
          {"cap":"슬로건|《책》", "say":"…. 교보문고에서 만나 보세요.", "evidence":"…", "img":null}],
 "end":{"slogan":"…","book":"《책》","by":"저자 지음 · 출판사","cta":"교보문고에서 만나 보세요","note":"효과에는 개인차가 있습니다"}}
```
규칙:
- **8줄 안팎, 소리 글 합계 ~160음절 = 약 30초**. 마지막 줄은 `img:null` → 끝 표지 카드
- `evidence` 에 책 원문을 「 」로 그대로 인용(중간 생략은 …). **원문에 없는 사실·숫자는 쓰지 않는다**
- **숫자**: `cap`(화면)은 아라비아 숫자 「10년」「2만 시간」, `say`(소리)는 한글 「십 년」「이만 시간」. `say` 에 영문·숫자 금지
- `cap` 의 `|` 는 자막이 바뀌는 지점(한 조각 15자 안팎)
- `img`: **영어로**, 인물의 국적·성별·나이·장소·조명을 구체적으로. 원문 속 인물과 성별·나이를 맞춘다. 거리·상점 장면은 가짜 간판 글자가 나오니 실내·공항·자연으로
- 광고 표현 금지: 효과·치료·기간 약속 단정(「한 달이면 들린다」) 쓰지 않는다 — 책에 있어도. `note` 는 그대로 둔다
- 목소리: `Jiseon`(여성) / `Hyunjun`(남성)

그다음 **반드시**:
```
PY tools/check_evidence.py books/<책>/part1.json      → 「근거 대조 통과」가 아니면 고친다
```

## 4. 만들기
```
PY make_part.py books/<책>/part1.json --no-render     ← 이미지·음성만 (돈이 드는 단계)
```
- 이미지는 `books/<책>/img/part1-NN.png`. **7장을 한 장으로 이어 붙여 직접 열어 본다**(이미지 읽기). 액자 속 그림·콜라주·글자/간판·성별 불일치·이상한 손이 있으면 그 번호만 다시: `--regen-img 3,5`
- 이상 없으면 렌더:
```
PY make_part.py books/<책>/part1.json
```
→ `books/<책>/out/part1.mp4`, `part1.qa.json`, `part1.frames.jpg`(프레임 5장). 종료코드 3이면 QA 실패 — 내용을 읽고 고친다.
- `frames.jpg` 를 **직접 열어** 자막 띄어쓰기·잘림·끝 카드 배치를 확인한다.
- 비용: 이미지 7장(Gemini) + 음성 8줄(Typecast). 같은 줄·같은 그림은 캐시라 다시 돈이 들지 않는다.

## 5. 사용자에게 보여 주기
mp4 와 frames.jpg 를 보여 주고 보고: 길이, QA 결과(LUFS·무음·끝 카드), 쓴 근거, API 호출 수, 「소리는 직접 듣지 않았음」. **올리기는 사용자 승인 후에만.**

## 6. 올리기 (승인 후)
`books/<책>/partN.upload.json` 을 쓴다(견본 `books/대충영어/part1.upload.json`): 제목(훅 + 책 이름 + 해시태그 2개), 설명(시처럼 끊은 카피 → 《책》 저자·출판사 → 구매 링크 → 「효과에는 개인차」 → 해시태그), 태그, 댓글(구매 링크).
- **쉬운 길(권장)**: 사용자가 YouTube Studio 에서 mp4 를 올리고, 「변경되거나 합성된 콘텐츠」= **예**(AI 이미지·합성 음성이므로 필수), 설명·제목 붙여넣기, 댓글 달고 ⋮ → **고정**.
- 자동: `PY upload.py books/<책>/part1.upload.json` (사전에 `secrets/client_secret.json` 필요 — README). 채널 이름을 묻고 y 를 받아야 올린다. 댓글 고정은 Studio 에서 손으로.

## 함정 (실제로 겪은 것)
- 예스24 는 크롬 전체 User-Agent 로 부르면 검색 결과 없는 페이지를 준다 → 코드는 `Mozilla/5.0` 만 쓴다
- 교보 검색의 첫 상품은 다른 판일 수 있다 → 코드가 「[국내도서] 제목」 일치로 고른다
- 이미지 모델이 액자·콜라주·가짜 간판을 그린다 → 프롬프트 스타일에 금지 문구가 들어 있고, 그래도 나오면 다시 뽑는다
- 자막 띄어쓰기가 사라지는 문제는 코드에서 해결됨(.cap 안 span)
- Windows 콘솔 한글 깨짐은 코드가 UTF-8 로 출력해 막는다. 그래도 깨지면 `chcp 65001`
- 렌더가 바로 실패하면 `npx --yes hyperframes@0.8.143 --version` 으로 크롬 다운로드부터 확인
